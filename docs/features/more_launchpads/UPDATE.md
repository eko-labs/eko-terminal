# More of long.xyz

EKO now follows long.xyz coins whose pools are priced in tokenized stocks (TTWO, SPCX, NVDA and others), WETH or USDG,
not only those priced in ETH. Every trade is priced in dollars, so price, market cap, volume and flow read like any
other coin's, and the same checks run: holders, launch snipers, dev dumps and fake market caps.

The sell check runs on these pools too: a round trip of about $1,000 in the pool's own quote, so the coin page shows
the exit cost at $1K. Where EKO has no balance reading for a quote token yet, the check is named not available rather
than guessed. long.xyz pools run Doppler's hook: EKO counts it reviewed where the pool's fee module has verified
source, and flags the rest as an unreviewed hook. EKO checks these coins but does not trade them: their pools run a hook
EKO does not trade through.
