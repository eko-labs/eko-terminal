# Security

If you find a vulnerability in EKO, report it privately:

- **GitHub:** use *Report a vulnerability* on this repository's **Security** tab, or
- **Email:** security@ekoterminal.com

Please include what you found, how to reproduce it, and what it affects. Do not open a public issue or test against
other people's funds. EKO does not run a bug bounty.

**In scope:** the live site at ekoterminal.com, its API, the checks and verdicts, wallet sign-in and trading, and the
contracts in [`contracts`](contracts).
